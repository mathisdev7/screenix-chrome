# macos_tahoe supplemental cursor artwork

Source: https://github.com/vinceliuice/MacTahoe-icon-theme/tree/839848b9a8a38a92a6936e30c4abe35cc6f2546d

Upstream MacTahoe cursor theme by vinceliuice. See LICENSE for its GPL-3.0 terms. This is the Linux theme artwork, not an Apple-provided asset distribution.

Preserved the source geometry, canvas padding and per-cursor hotspots. Recolored the grab, grabbing and move hand artwork with white interiors and black outlines. Set SVG output dimensions to 256 pixels; square-padded any non-square viewBox without scaling the geometry. Busy and progress use the first animation frame. Roles sharing an image follow upstream aliases or use an equivalent role from this same theme. No artwork is borrowed from another theme.
