# Mocu cursor artwork

Source: https://github.com/sevmeyer/mocu-xcursor/tree/efdd71279b79bf1e2566c38becc5e7c4ab2d900c

Author: sevmeyer. License: CC0-1.0; see LICENSE.txt.

Original right-handed black SVG artwork, with the original white variant for pointing, grab, grabbing, and move hands. Color placeholders are resolved to upstream theme colors. Hotspot markers and baked shadow layers are removed. The native 24-unit canvas has one unit of additional padding on each side to avoid clipped outlines. SVG dimensions are 256 by 256, with viewBox -1 -1 26 26. Hotspots come from each source SVG and include the canvas offset. Busy/progress use the first static frame. Upstream move aliases to grabbing; all-resize uses all-scroll and handwriting uses pencil. No artwork from another theme is used.
